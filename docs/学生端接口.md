# 学生端后端接口

> 2026-10-27。学生端任务 S01—S10 及教师选材下发已实现，本轮只交付后端和接口。全量 711 项测试通过，未新增模型、迁移或外部依赖，未修改业务库。
> 认证与既有接口见 [API设计文档](API设计文档.md)，任务落实见 [学生端任务清单](学生端任务清单.md)。

## 1. 纯 API 会话接入

1. GET `/api/auth/csrf/`，保存响应 Cookie，读取 JSON 的 csrfToken；响应禁止缓存，CSRF Cookie 仍为 HttpOnly。
2. POST `/api/auth/login/`，JSON 为 username/password，携带 Cookie 与 X-CSRFToken。登录后 CSRF 轮换，使用登录成功响应新增的 csrfToken，或再次 GET csrf 接口。
3. mustChangePassword=true 时先 POST `/api/auth/change-password/`，提交 oldPassword/newPassword。CSRF 引导、本人权限和改密闭环允许访问，其余业务仍由中间件拦截。
4. 改密成功保留当前会话。后续写请求继续携带 Cookie 和当前 token。跨源伪造、缺 token、无效 token 仍被拒绝。

登录 username 最长 150 字，密码及改密字段最长 1024 字；只接受允许字段的对象、有效字符串且无 NUL。密码保留首尾空格。无效结构或类型返回 400，业务响应和日志不输出密码。既有本人资料仍用 GET/PATCH `/api/auth/profile/`，学生可改 name/email。

## 2. 两种读取范围

学生本人由会话决定，新聚合接口同时要求学生组及对应功能权限；不能通过 studentId/userId 参数切换本人。无身份、首个学生身份缺档案，不回退到后一个身份。学校身份和学籍只读。

| 资源 | 资格 |
|---|---|
| 作业题面、参考答案、班级通知、资料和提醒 | 在读、当前在相应行政班；关闭/归档学期还须属于该教学班冻结名单。原开始时间、截止后答案公开等条件继续执行 |
| 本人历史作业摘要、分数及反馈 | 当前内容资格，或冻结名单中的本人，或该作业存在本人提交；只返回本人数据 |
| 本人原提交及代码 | 保留既有 user=当前用户的历史访问，不因转班删除或开放他人提交 |
| 课程组知识、共享库和原章节 | 不向学生直接开放；教师选材下发后，学生读取独立的班级资料副本 |

休学、毕业、退学或离班后仍可查符合条件的本人历史摘要、成绩和反馈，不能因此恢复原班题面、答案、通知及资料资格。关闭后转入的学生不能单凭当前行政班相同继承旧学期内容。正式关闭/归档学期缺少冻结记录时，对其内容读取默认拒绝。

权限不足返回 403；单个对象不存在或无权访问返回相同 404；列表越界筛选返回空集。无效筛选为 400；分页沿用 DRF 的无效页/越界页 404。

## 3. 接口速查

全部新聚合接口以 `/api/student/` 为前缀，均为 GET，响应带 private, no-store。

| 路径 | 权限 | 功能 |
|---|---|---|
| context/ | profile:edit | 本人学校身份、学籍、专业学院、当前行政班及当前学期编码 |
| teaching-classes/ | homework:view | 本人当前及历史课程/教学班摘要，含任课教师显示名；无同学名单 |
| homeworks/ | homework:view | 作业分页、筛选及本人结果概要 |
| `homeworks/<homeworkId>/grades/` | homework:view | 本人逐题成绩、最新提交与最近教师反馈 |
| notices/ | notice:view | 本人当前可读通知聚合、未读筛选及数量 |
| materials/ | material:view | 本人当前可读班级资料聚合，实际下载使用原授权接口 |
| dashboard/ | 学生入口，各卡片单独核验原权限 | 首页作业、截止提示、最近提交和消息概况 |
| analysis/ | analysis:view_self | 本人学习统计、课程维度与提交趋势 |

teaching-classes/homeworks/notices/materials 每页 20 条，返回 count/next/previous/results；context、dashboard、grades、analysis 不分页。重复查询字段、未知字段和伪造本人 ID 参数均拒绝。

### 3.1 本人上下文与课程

context 返回 user、identity、student、adminClass、currentTerm。student 含 academicStatus/enrollmentYear/major，major 含 department 摘要；缺身份/档案/当前成员分别返回 null，不创建资料或自动重新入班。不接受 PATCH。

teaching-classes 支持 page/courseId/teachingClassId/term/scope。每项字段为 id/name/term/termStatus/course/teachers/contentAvailable/isHistorical；只列课程及教师简要信息，不返回 classmates、全班人数或成绩。

scope=all 为默认，current 表示仍有当前内容资格的集合，history 表示只剩本人历史摘要资格的集合。仍在班且属于冻结名单的旧学期可归入 current；学期 open/closed/archived 另由 termStatus 表达，不能把 scope 当作学期状态。

### 3.2 作业列表

homeworks 支持 page/courseId/teachingClassId/term/scope/q/status/submissionState。q 搜索标题且最长 100 字；term 最长 20 字。

- status 为 pending_start/ongoing/closed，表示作业时间状态。
- submissionState 为 not_submitted/partial/submitted，表示本人是否每题均有提交，不表示是否 AC。
- 新字段包含 teachingClassId/teachingClassName/courseId/courseName/term/termStatus/teacherName/startAt/deadline。
- 本人结果包含 problemCount/submittedProblemCount/scoredProblemCount/passedProblemCount/submissionCount/mySubmitCount/pendingCount/score/myBestScore/totalScore/submissionState/gradingComplete/passed/unreviewedCount。
- contentAvailable 表示当前可读题面，canSubmit 还要求开放学期和进行中的作业。未开始只给概要；isHistorical 表示无当前内容资格；answersAvailable 仍要求当前资格、已公开且严格晚于截止。
- scoreSource 为 live 或 archive，gradeAvailable 表示是否有本人结果行。归档没有本人行时不按实时提交捏造成绩。

列表额外返回 asOf，整页使用同一统计时间。mySubmitCount 保留提交次数语义，submittedProblemCount 才是已提交题目数。

旧 GET `/api/homeworks/` 仍返回数组，不改为分页；其 teacherName 使用 User.name，归档 myBestScore 同样读取冻结本人结果。

### 3.3 本人作业结果

GET `homeworks/<id>/grades/` 返回作业概要、studentId 和本人 problems 数组。开始前返回 404；历史摘要资格不扩展为题面或答案资格。

每题包含 problemId/title/totalScore/score/passed/submissionCount/pendingCount/reviewedCount/lastSubmittedAt/state，以及 latestSubmission、teacherReview、feedbackSubmissionId。最新提交与最近评阅可属于不同提交，不能因最新提交尚无批语而隐藏之前反馈。

latestSubmission 仅含 id/status/score/createdAt/judgedAt；teacherReview 使用已有安全字段。完整代码和全部反馈继续通过本人提交列表、详情查询，不从教师成绩响应中截取或返回其他学生行。

每题取最高有效终态分数，再合计；queued/running/system_error/repeat 不贡献有效分，无有效结果为 null。再次排队不抹掉已有得分。归档成绩、计数及题目展示采用冻结成绩中本人行，原始提交状态作为独立追溯信息展示。

### 3.4 通知、提醒与资料

notices/materials 支持 page/q/courseId/teachingClassId/term，仅使用当前内容资格。notices 另支持 unread=true|false，并返回 unreadCount；数量遵从课程/标题等筛选，在未读筛选和分页前统计。

原 `/api/reminders/` 兼容增加 unread=true|false 和响应 unreadCount，其余分页/已读协议不变。通知已读继续 POST `/api/notices/<id>/read/`，提醒已读继续 POST `/api/reminders/<id>/read/`，请求体为 `{}`，反复阅读保留首次时间。

资料列表不读取文件、不返回物理路径。下载继续 GET `/api/materials/<id>/download/`，每次重新校验班级及冻结名单；摘要或历史成绩资格不能用于下载。通知修改保留首次已读，不宣称读过最新版本。

### 3.5 首页

dashboard 返回 asOf、sections、homeworks、notices、materials。sections 表示相应原功能权限；某类权限被撤销时，该卡片为 null，不通过画像或首页入口继续读取。

作业卡片统计未开始、进行中、进行中未交齐、已截止未交齐，提供未来 72 小时内未交齐作业数量和最先截止的 5 条，以及本人最近 5 次提交。仅当前内容资格进入待办，历史成绩不生成待交任务。

通知卡片返回未读通知、未读提醒数及最近 5 条可读通知；资料卡片返回可读班级资料数量。不因菜单/卡片被页面隐藏而省略后端权限检查。

### 3.6 学习画像

analysis 支持 days/courseId/teachingClassId/term；days 默认 30，范围 1～366。窗口为 asOf 往前连续 days×24 小时，作业按开始时间进入窗口且必须已开始，提交趋势按实际提交时间进入窗口并按学校时区分日。

返回 asOf/windowStart/days、summary、courses、submissionTrend。统计为本人作业数、已提交/交齐/已有齐全有效成绩/通过作业数、completionRate、averagePercent 和待判数；趋势包含提交、AC、待判、系统错误次数。

completionRate 为交齐作业数/作业数，空集合为 null；averagePercent 只统计各题均有有效成绩且总分非零的作业，先按各作业百分制计算再取个人平均，空集合为 null。这是展示统计，不是学校课程正式总评或加权成绩，不提供全班均分、排名或其他人数据。

## 4. 教师选材下发

POST `/api/teacher/teaching-classes/<teachingClassId>/materials/from-course/`，要求教师入口、material:class_manage 及目标教学班实际任课关系。

```json
{"materialId":12,"chapterId":3,"title":"本周选读","description":"课堂学习资料"}
```

仅 materialId 必填，chapterId/title/description 可选。省略展示字段时沿用源资料字段；chapterId 指定时必须为同一课程×学院的可见章节且已关联该资料。

目标须为开放学期。源资料须属于目标教学班的 CourseCollege；course 可见资料可下发至该课程的本人任课班，classes 可见资料必须明确包含目标教学班。教师即使同时教其他班，也不能凭另一班的可读资格越过源资料范围。

锁定并重查任课、学期、课程及可见范围后才打开私有源文件，校验实际大小，复制到班级私有存储并创建 TeachingMaterial，返回原班级资料元数据，状态 201。文件上限 50MiB，班级资料后缀兼容新增 json，始终以附件下载。

下发结果是独立副本。源资料之后修改、替换或删除不改变已下发内容；需要新版时教师显式再次下发，形成新班级资料，不自动覆盖或去重。学生不获得源库或章节/知识库原文访问资格。

事务失败清理新文件，审计记录 material.publish_shared、来源资料/章节 ID、目标班及安全元数据，不记文件正文和物理路径。
