# 非学生端后端接口

> 2026-10-27。本文对应教务、教师及课程组后端新增接口；学生端清单及后续教师选材下发见 [学生端接口](学生端接口.md)。非学生端 5 项迁移已在本地业务库备份后验收，学生端阶段无新增迁移，生产环境独立验收。

## 1. 接入约定

沿用 Session 认证。JSON 写请求携带 `X-CSRFToken`，文件请求使用 multipart；登录流程见 [API设计文档](API设计文档.md)。纯 API 可从 GET `/api/auth/csrf/` 获得 token，登录后使用响应中的轮换 token；原 `/login/` 表单保留。CSRF Cookie 为 HttpOnly，不能依靠脚本读取 Cookie。

资源编号为正整数，`studentId`、`accountId` 均是 **User.pk**；`courseCollegeId` 是课程×学院设置的编号。成功创建一般为 201，后台导入受理为 202，删除一般为 204。参数与业务规则错误为 400，功能权限不足为 403，对象不存在或越权为 404。错误体可能是 `error`、`detail`、字段字典或错误列表。

分页列表默认 20 条，使用 `page`；DRF 列表返回 `count/next/previous/results`。学期列表不分页；审计每页 50 条；导入历史和错误列表使用 `count/page/results`，错误每页 100 条。原有 `/api/courses/` 等列表返回契约保留。

本轮沿用 22 个权限码。只有教师实际任课关系能授予教学班访问；课程教师池本身不授予教师读取教学数据的权限。

## 2. 教务基础维护

以下集合支持 GET/POST，`<id>/` 支持 GET/PATCH/DELETE：

| 路径 | 权限 | 可写字段 |
|---|---|---|
| `/api/office/departments/` | `course:manage` | `code` ≤32、`name` ≤100、`isActive` |
| `/api/office/majors/` | `course:manage` | `departmentId`、`code` ≤32、`name` ≤100、`isActive` |
| `/api/office/courses/` | `course:manage` | `code` ≤20、`name` ≤50、`isActive` |
| `/api/office/admin-classes/` | `class:manage` | `majorId`、`enrollmentYear`、`code` ≤32、`name` ≤50、`isActive` |

创建学院、课程要求 code/name；专业额外要求 departmentId；行政班要求 name/majorId/enrollmentYear，code 可以省略。isActive 默认 true，PATCH 只提交需修改字段。

列表支持 `q`（名称/编码，≤100 字）、`isActive=true|false`；专业列表额外支持 `departmentId`，行政班列表额外支持 `majorId`。返回 id 及表中的业务字段。

- 学院有专业、课程开设或教师档案时不可删除；专业有行政班、学生档案时不可删除。
- 课程有学院开设关系时不可删除或更改编号；行政班有成员历史、课程候选关系或教学班关系时不可删除，专业及入学年也不能改变。
- 专业已有行政班或学生档案时，不能改所属学院。编码唯一冲突返回 400。
- 停用保留现有组织及历史，阻止新的相关组班、候选班、入班和导入；停用不会撤销已有历史读取资格。
- 关联归档教学班的基础数据只允许单独修改 isActive；其余资料修改受历史保护。

原有课程学院分配、组长任命、教学班组成与任课分配仍走 [API设计文档](API设计文档.md) 第三章。创建教学班的 term 必须已登记；省略时使用数据库中的当前学期，不再使用代码常量。

## 3. 账号与学籍

| 方法与路径 | 功能 |
|---|---|
| GET `/api/office/accounts/` | 账号分页，支持 q、role=teacher|student、isActive=true|false |
| GET/PATCH `/api/office/accounts/<accountId>/` | 查询、维护账号资料 |
| POST `/api/office/accounts/<accountId>/reset-password/` | 系统管理员重置他人密码 |
| PATCH `/api/students/<studentId>/academic/` | 学籍状态、专业及入学年异动 |

账号接口要求 `class:manage`。教务仅管理普通教师或学生；staff、superuser、教务、课程组及具有额外权限的账号不进入其可管理集合。系统管理员可管理高权限账号。接口不接受修改 username、学校身份、分组或权限。

账号 PATCH 可写 `name`、`email`、`isActive`，有教师档案时可写 `title`、`departmentId`（允许 null）。不能通过该接口停用自身。返回 `id/username/name/email/isActive/mustChangePassword/groups/identities`；学校身份中按类型包含教师或学生档案摘要，不返回密码散列。

重置密码仅接受 `{"password":"新密码"}`，只允许系统管理员重置他人；本人使用原个人改密接口。执行 Django 密码策略，成功返回 `id/mustChangePassword`；旧会话失效，用户再次登录后必须改密。密码不进入审计。

学籍维护要求 `class:manage`，字段为 `academicStatus`（在读/休学/毕业/退学）、`majorId`、`enrollmentYear`、可选 `adminClassId`。学生选择沿用首个学生学校身份规则，无档案不回退到后一个身份。

```json
{"academicStatus":"在读","majorId":12,"enrollmentYear":2025,"adminClassId":18}
```

非在读状态结束当前成员关系；恢复在读不自动回班。更改专业或入学年也先结束原成员关系；显式提供新班时必须与变更后的专业、入学年一致，且班级、专业及学院启用。办理日期取服务器本地当日，不接受客户端伪造。所有步骤同事务，保留账号、旧成员和原提交。

普通同专业同年级转退班及成员历史接口继续使用 `/api/students/<id>/{transfer,leave,memberships}/`。非在读学生不能通过普通转班重新入班。Django 后台维护学生状态也调用相同异动服务。

正式学号格式仍待确定。旧 student 自动分班类型保持原 8 位占位解析；指定班导入 class_student 使用合法编号，不依赖该占位规则。

## 4. 学期生命周期

统一要求 `course:manage`：

| 方法与路径 | 请求与用途 |
|---|---|
| GET/POST `/api/office/terms/` | 列表；创建 code/name/startDate/endDate |
| GET/PATCH `/api/office/terms/<id>/` | 查询；修改 name 或成对修改 startDate/endDate |
| POST `/api/office/terms/<id>/current/` | `{}`，设为唯一当前学期 |
| POST `/api/office/terms/<id>/close/` | `{}`，关闭并冻结各教学班名单 |
| POST `/api/office/terms/<id>/archive/` | `{}`，归档并冻结各作业成绩 |

code ≤20 字、name ≤50 字，日期格式 YYYY-MM-DD 且结束不早于开始。创建时日期必填；历史迁移的学期日期为 null，须由教务配置。返回 `id/code/name/startDate/endDate/status/isCurrent/closedAt/archivedAt`。

状态只能由 open → closed → archived；无公开反向恢复、删除或直接改 status 接口。当前学期必须 open。关闭后清除该学期 current 标志，切换当前学期不自动关闭旧学期。日历日期是管理信息，状态转换由教务显式执行。

| 状态 | 行为 |
|---|---|
| open | 可组班、分配任课、发布作业、提交、维护通知资料及评阅 |
| closed | 名单冻结；禁止新组班、组成/任课变更、作业/通知/班级资料写入、新提交和提醒；允许评阅与参考答案收尾 |
| archived | 名单和成绩冻结；教学写入只读；任课教师仍可查询看板、成绩及导出 |

仍有未截止作业时禁止关闭。仍有 queued/running 提交时禁止归档；关闭前已受理的判题可完成。关闭、归档重复执行不重复建快照。

关闭名单包含当时当前成员及已经离班但留下本班作业提交的学生；之后毕业、转班或修改账号姓名不改变该名单。归档逐题成绩沿用最高有效分统计，不改动原始提交。教师班级列表、详情、看板和成绩读取冻结口径。

课程组全局知识和共享库可继续维护，不冻结整套资料版本；已涉及归档教学班的资料可见范围禁止改变或删除，资料内容允许修正。它不会改写已冻结的作业题面或成绩。

## 5. 教务后台导入

| 方法与路径 | 功能 |
|---|---|
| GET/POST `/api/import-jobs/` | 历史 / 提交 multipart 文件 |
| GET `/api/import-jobs/<id>/` | 进度与统计 |
| POST `/api/import-jobs/<id>/retry/` | 失败或部分成功后重新上传 file 重试 |
| GET `/api/import-jobs/<id>/errors/` | 错误分页，每页 100 |
| GET `/api/import-jobs/<id>/errors/download/` | UTF-8 BOM CSV 错误明细 |

基础权限 `class:manage`；只返回本人批次，系统管理员可看全部。历史过滤为 type/status。POST 字段为 type/file，加与类型相符的目标 ID：

| type | 目标 | 额外权限 |
|---|---|---|
| course | 无 | `course:manage` |
| teacher | 无 | 无 |
| student | 无，旧占位学号自动分班 | 无 |
| class_student | adminClassId | 无 |
| course_teacher | courseCollegeId | `class:assign_teacher` |

xlsx 上限 10MiB、解压总量 64MiB、10000 物理数据行；首行为表头，A 编号、B 姓名/课程名称、C 初始密码。空行跳过，错误行号保持 Excel 物理行号。班级或课程停用时禁止导入。课程教师导入只自动分配开放学期的教学班，不追溯增加已结课任课。

受理返回 202，字段为 `id/type/status/originalName/createdBy/adminClassId/courseCollegeId/total/completed/progress/successCount/errorCount/error/attempt/retryable/createdAt/startedAt/finishedAt`。

状态为 pending/running/succeeded/partial/failed。默认 codemind worker 每段最多处理 100 个有效行或约 60 秒，再续投；每行业务与游标同事务。后台逐行重查权限，撤权或停用会停止后续行。同一人最多 3 个活动批次。

重试须重新上传文件，保留批次 ID，增加 attempt 并更新本轮统计、行错误；上轮统计保留在审计中，行明细需提前下载。已有编号不覆盖密码或姓名，重复行报错。队列消息只传批次 ID 与轮次。

原文件私有保存，终态立即删除；清理未完成时不能重试。每分钟回收过期批次、重试清理并清除超过 24 小时的无引用源文件。结果和错误下载不含原始密码、物理路径或原文件下载链接。详细恢复及部署规则见 [异步任务设计](异步任务设计.md)。

## 6. 审计查询

`GET /api/office/audit-events/` 要求 `class:manage`，每页 50 条。筛选支持 `action/objectType/objectId/actorId/since/until`，时间为 ISO 时间。

返回 `id/actorId/actorUsername/action/objectType/objectId/before/after/createdAt`。记录操作者、对象及显式挑选的变化字段；不接受增删改审计的公开接口。账号与学籍、基础维护、原组织分配接口、学期、导入和课程组操作随业务事务记录；Django 后台账号、角色与组织变更同时记录审计并保留原生 LogEntry。

知识正文仅记录散列及元数据；密码、题目隐藏数据、上传正文和私有物理路径不记录。账号删除后 actor 外键可置空，操作者账号快照及目标 ID 留存。直接数据库或运维脚本改动不自动生成接口审计。

## 7. 课程组知识、章节与共享资料

以下路径统一以 `/api/course-team/` 开头。管理操作同时校验功能权限与该 CourseCollege 的 leader 任职，系统管理员放行。单纯持有课程组分组不能管理其他负责人课程。

| 路径 | 方法 | 权限与功能 |
|---|---|---|
| course-colleges/ | GET | `knowledge:manage`，本人负责课程分页 |
| course-colleges/<ccId>/knowledge/ | GET/POST | `knowledge:manage`，知识列表/创建 |
| knowledge/<id>/ | GET/PATCH/DELETE | 知识详情/维护 |
| course-colleges/<ccId>/knowledge/import/ | POST | file 为 JSON 数组，批量导入条目 |
| course-colleges/<ccId>/documents/ | POST | multipart 文档导入并解析 |
| knowledge/<id>/reparse/ | POST | `{}`，重新解析原文档 |
| knowledge/<id>/download/ | GET | 受保护下载文档原文件 |
| course-colleges/<ccId>/chapters/ | GET/POST | `chapter:manage`，章节列表/创建 |
| chapters/<id>/ | GET/PATCH/DELETE | 章节详情/维护 |
| course-colleges/<ccId>/chapter-order/ | POST | chapterIds 为本课程全部章节的最终顺序 |
| course-colleges/<ccId>/materials/ | GET/POST | `material:class_visible`，共享资料列表/上传 |
| materials/<id>/ | GET/PATCH/DELETE | 资料详情/维护 |
| materials/<id>/download/ | GET | 受保护下载 |

知识条目字段为 `title` ≤100、`content` ≤100万字、可选 `isVisible` 默认 true；列表支持 q（标题/正文）、kind=entry|document、status=ready|failed，返回元数据和 200 字 excerpt；详情返回 content。

条目批量导入为 UTF-8 JSON 数组 `[{"title":"...","content":"...","isVisible":true}]`，1～1000 条，整批验证及写入；返回 count/knowledgeIds。文档导入字段为 title/file/isVisible，支持 UTF-8 txt/md/csv/json 和标准 docx，上限 8MiB、DOCX 解压 32MiB、正文 100万字。同步解析返回 ready 或 failed/parseError，失败仍可查询、下载、替换和重试；不接 OCR 或外部 AI。文档 PATCH 可换文件或元数据，正文由解析产生，不能直接伪造。

章节字段为 title/description/isVisible/knowledgeIds/materialIds，创建自动追加 position。关联 ID 只能来自本课程。排序须提供完整、去重的 chapterIds，失败整批回滚。资源已被章节引用时须先显式解除关联才能删除。

共享资料字段为 title/file/description/visibility/teachingClassIds。visibility=course（默认）面向本课程任课教师；classes 要求非空、同 CourseCollege 且不重复的教学班数组，course 模式不能附带指定班。文件上限 50MiB，后缀为 pdf/doc/docx/xls/xlsx/ppt/pptx/txt/md/csv/json/zip/c/py。替换及删除在事务提交后清旧文件，失败清理新文件。

资料及文档使用 UUID 私有存储名，接口只给原名、大小等元数据。下载先完成授权再打开文件。并发请求更改范围时重新核验，普通元数据修改保留最新可见范围。

## 8. 教师读取课程组资源

全为 GET，以 `/api/course-team/teacher/` 为前缀：

- course-colleges/
- course-colleges/<ccId>/knowledge/、materials/、chapters/
- knowledge/<id>/、materials/<id>/、chapters/<id>/
- knowledge/<id>/download/、materials/<id>/download/

教师必须实际任教该 CourseCollege 的至少一个教学班，含保留任课关系的历史学期；撤销最后一项任课后立即失去访问。只有 ready 且 visible 的知识、visible 章节可读；指定班资料按该教师实际任课关系过滤。章节关联 ID 同样裁去不可读资源。教师无源库写入接口，学生不直接接入共享库。

教师可 POST `/api/teacher/teaching-classes/<id>/materials/from-course/`，用 materialId 及可选 chapterId/title/description 选材下发。要求 `material:class_manage`、目标班实际任课、开放学期和源资料对该目标班可见；只生成独立班级副本，不修改源库，不开放学生知识原文。完整契约见 [学生端接口](学生端接口.md#4-教师选材下发)。
