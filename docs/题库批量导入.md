# 题库批量导入说明（系统管理员）

> 适用范围：系统管理员通过 `/admin/` 或管理员 API 向公共题库批量导入题目
> 更新时间：2026-10-20
> 相关设计：`docs/OJ对接设计.md` 第 12.5 节

## 一、权限口径

- 公共题库**只有系统管理员（superuser）**可以导入、编辑、删除。
- 所有教师可以查看公共题库、在作业中选题，但不能修改。
- 教师个人题库不受影响，教师仍可自建个人题。

管理员入口：

1. 后台页面：登录 `/admin/` → 「题目」→ 右上角「批量导入题库」
2. 管理员 API：`POST /api/admin/problems/import/`
   - multipart 字段：`file`（ZIP 文件）、`overwrite`（可选，`1`/`true`/`on`）
   - 使用项目现有 Session 认证；脚本调用需先登录并携带 CSRF token，
     日常导入建议直接使用后台页面

## 二、导入包结构

```
题库导入包.zip
├── manifest.xlsx        # 清单（必需；也接受 manifest.csv）
├── p0001.md             # 每题一个 markdown 文件
├── p0002.md
└── ...
```

注意：

- 清单和 md 文件放在 ZIP 根目录即可；子目录也可以，但 `file` 列要写相对路径。
- ZIP 内除清单和 `.md` 外的文件（如 README、图片）会被忽略。
- 文件名建议使用 ASCII（如 `p0001.md`）；中文文件名已做兼容处理，但不同压缩工具编码可能不同，ASCII 最稳。
- ZIP 内不能有重名文件，不能使用 `../` 等路径穿越写法。

## 三、清单格式

首行为表头，列名不区分大小写、空格、下划线和连字符。

| 列 | 必填 | 说明 |
|---|---|---|
| `file` | 是 | ZIP 内 md 相对路径，如 `p0001.md` |
| `code` | 否 | 稳定题目编号；缺省用 `file`。重复导入靠它判断是否为同一题 |
| `tier` | 否 | `beginner` / `basic` / `advanced`，或 入门/基础/进阶；默认 `basic` |
| `languages` | 否 | `c,python`、`c`、`python`；支持 `、`、`，`、`/` 分隔；默认两者 |
| `compareStrategy` | 否 | `exact` / `trailing` / `loose`，或 精确比对/忽略行尾空白/忽略全部空白；默认 `exact` |

示例（`manifest.xlsx`）：

| file | code | tier | languages | compareStrategy |
|---|---|---|---|---|
| p0001.md | C0001 | basic | c,python | exact |
| p0002.md | C0002 | advanced | c | trailing |

`manifest.csv` 需使用 UTF-8 编码（带 BOM 也可以）。

## 四、题目 markdown 格式

沿用现有单题录题格式，详见 `docs/OJ对接设计.md` 第十章。最小示例：

````markdown
# 两数之和

给定两个整数，输出它们的和。

```input-sample
1 2
```
```output-sample
3
```

```input
1 2
```
```output
3
```
````

约定：

- 第一个 `# 标题` 作为题目名称（必填，≤100 字符）。
- `input-sample` / `output-sample`：公开样例，可省略。
- `input` / `output`：隐藏测试点，至少一组，最多 20 组；可在围栏信息里写 `points=N`。
- `spj-python`：可选的特殊判定代码，每题至多一个。
- 单个 md ≤6MB；单组测试点数据 ≤256KB。

## 五、重复导入与覆盖

导入时按 `code` 查找已有题目：

| 情况 | 未勾选「覆盖」 | 勾选「覆盖」 |
|---|---|---|
| code 不存在 | 新建题目 | 新建题目 |
| code 存在，内容完全相同 | 跳过 | 跳过 |
| code 存在，内容有变化 | 报错，不修改原题 | 更新题目，`revision+1` |

「内容」包括 markdown 原文和 tier/languages/compareStrategy。修改清单里的档位或语言也会被视为内容变化。

## 六、导入结果

导入完成后页面会显示：

- 清单题目总数、新建数、更新数、跳过数、错误数
- 每个失败文件的文件名和原因
- 最近 10 次导入记录

常见错误原因：

| 原因 | 处理 |
|---|---|
| 清单缺少 file 列 | 检查表头 |
| 清单引用的文件不存在 | 检查 `file` 列与 ZIP 内路径 |
| 文件未在清单中登记 | 为 ZIP 内每个 md 补一行清单 |
| markdown 缺少一级标题 / 测试点 | 按第四章格式修正 |
| 题目已存在且内容有变化（未勾选覆盖） | 需要更新时勾选「覆盖」 |
| 单批最多导入 2000 道题 | 拆成多个 ZIP |

## 七、限制

| 项目 | 上限 |
|---|---|
| 单批题目数 | 2000 |
| ZIP 文件大小 | 64MB |
| ZIP 解压后总大小 | 256MB |
| 单个 md | 6MB |
| 单个测试点数据 | 256KB |
| 单题测试点组数 | 20 |
| 单题公开样例组数 | 20 |

约 1000 道题的常规题包（每题几十 KB）可以一次导入；同步执行通常在数秒内完成。

## 八、导入后检查

1. 在 `/admin/teaching/problem/` 查看题目数量与标题。
2. 用教师账号进入「作业题库」页，搜索题目标题，确认可见。
3. 在任一教学班「作业」Tab 新建作业，选题面板能搜到并勾选导入的题目。
4. 学生端作业详情能正常显示题面与公开样例；隐藏测试点不会下发。
